# 14-taximeter（打车计价）

Taximeter — 起步价 + 里程价 + 低速时长费（夜间加价系数）+ 空驶补公里

## 空驶补公里

打表时除载客公里、低速分钟外可提交空驶公里：空驶段不加起步、不计低速、不吃夜间系数，
只按 `空驶单价 × 空驶公里` 计费。运价页维护空驶单价（必须为正，仅允许一条启用，
冲突时 409 并点名两条标识）；全部停用时空驶费为零。回包分载客三项（起步/里程/低速）、
空驶费与应付（= 载客合计 + 空驶费）。空驶为负整单 422 拒绝且不写记录；
`persist=false` 只读试算不写 `calc_runs`；已写入记录保留当时空驶公里与空驶费快照，
后续改单价不回改。

## 启动

```bash
docker compose up --build
```

| 入口 | 地址 |

## 主链

录行程里程与低速时长 → 拆解车费 → 行程单
