# 14-taximeter（打车计价）

Taximeter — 起步价 + 里程价 + 低速时长费（夜间加价系数）+ 空驶补公里（空驶单价 × 空驶公里，不加起步、不计低速、不乘夜间系数）

## 空驶补公里

- 打表同时提交载客公里、载客低速分钟与空驶公里；应付 = 载客应付 + 空驶费。
- 空驶单价在「运价」页维护（列表/新增/改价/启用停用），只允许一条启用且单价必须为正，冲突时返回 409 并点名两条标识。
- 全部停用或未配置时空驶费为 0；空驶公里为负整单拒绝（422）且不写 calc_runs。
- 只读试算（persist=false）不落库；已写入记录快照当时空驶公里与空驶费，事后改单价不改写历史。

## 启动

```bash
docker compose up --build
```

录行程里程与低速时长 → 拆解车费 → 行程单
